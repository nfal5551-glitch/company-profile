=== GitHub Pages ===
1. Buat repo baru
2. Upload SEMUA isi folder lokeria-id (termasuk folder images)
3. Settings → Pages → Source: Deploy from branch → main → / (root)
4. Tunggu 1–2 menit, buka https://USERNAME.github.io/NAMA-REPO/
5. Hard refresh (Ctrl+F5)

=== Jika gambar hilang di GitHub ===
- Cek di repo: apakah folder images/ terlihat dan isinya banyak file?
- Jangan hanya upload file .html
- Nama file harus sama persis (huruf kecil): google-logo.png bukan Google-Logo.PNG
- Jangan taruh index.html di luar folder yang berisi images/
